# Phase 9b: Reflect, ideate, ideas slot, new outreach candidates — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** After a big event she also writes a reflection and an idea about the user; ideas reach
her next reply once (or become a reach-out), and her own recent thoughts become reach-out
candidates; a make-up reach-out marks the make-up offered (B26).

**Architecture:** The existing `user_mind_run` batch grows from one loop to three
(`user_summarise` → `user_reflect` → `user_ideate`), each through `runUserLoop` with its own
trace. Reflections and ideas are `fact` rows with two new kinds; reflections join normal
retrieval, ideas get a reply slot and two outreach paths, and are retired by the cold path or the
reach-out send transaction. A `core_thought` candidate reads core memory through `CoreMemory`.

**Tech Stack:** TypeScript, Drizzle + Postgres 16 (pgvector), Vitest, pg-boss, zod.

**Spec:** `docs/superpowers/specs/2026-10-09-phase-9b-reflect-ideate-design.md` (read it with
this plan). Project rules: `CLAUDE.md`, `spica-design-spec-v3.md`.

## Global Constraints

- `src/mind` is framework-free: no `Date.now()`, no `process.env`; time from `deps.clock`.
- Every numeric constant goes in `config/default.json` and the zod schema in
  `src/mind/platform/config.ts`; each new value gets a one-line `DECISIONS.md` entry.

- Comments say why, not where from: never cite spec sections, phases or backlog ids in code.
- Every file starts with a short plain-English header; Prettier at 100 columns.
- Scope: user loops read this user's memory and state plus the snapshot text only; they get no
  `core` layer. `core_thought` reads core through `deps.core.memory` only (no user id).
- Drizzle domain property names are snake_case; timestamps never `DEFAULT now()`.
- Done = `pnpm typecheck`, `pnpm lint`, `pnpm test` (includes the 9b exit and the canary) pass.
- Commit after each task; end commit messages with
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **A reflect or ideate failure mid-run** must not lose the summary or stop the next loop; the
   run ends `failed`, earlier writes stay. (Task 3 test.)
2. **An idea shown in a reply whose cold path is retried** must be retired once, idempotently,
   and a crisis reply must retire nothing. (Task 4 tests.)
3. **Ideas and reflections must never be read back as user facts by extraction/reconcile**: the
   extractor can't emit those kinds, reconcile never merges into them. (Task 1 tests.)
4. **A `core_thought` must reach each user at most once even if it is also her `her_day`**
   (shared `core:<id>` topic). (Task 5 test.)
5. **The idea that wins a reach-out must not also appear in a later reply's slot**, and a
   dropped reach-out must leave the idea live. (Task 6 tests.)

```ts
export async function recentReflections(db: Db, userId: string, limit: number): Promise<FactRow[]> {
  return db
    .select()
    .from(fact)
    .where(
      and(
        eq(fact.user_id, userId),
        eq(fact.kind, "reflection"),
        notInArray(fact.status, ["superseded", "stale"]),
      ),
    )
    .orderBy(desc(fact.created_at))
    .limit(limit);
}

/** Ideas she hasn't had her chance with yet: open, and not older than `since`. */
export async function liveIdeas(
  db: Db,
  userId: string,
  since: Date,
  limit: number,
): Promise<FactRow[]> {
  return db
    .select()
    .from(fact)
    .where(
      and(
        eq(fact.user_id, userId),
        eq(fact.kind, "idea"),
        eq(fact.status, "open"),
        gt(fact.created_at, since),
      ),
    )
    .orderBy(desc(fact.created_at))
    .limit(limit);
}

/** An idea gets one chance: once offered, it is resolved. Only open ideas move. */
export async function retireIdeas(db: Db, userId: string, ids: string[]): Promise<number> {
  if (ids.length === 0) return 0;
  const rows = await db
    .update(fact)
    .set({ status: "resolved" })
    .where(
      and(
        eq(fact.user_id, userId),
        eq(fact.kind, "idea"),
        eq(fact.status, "open"),
        inArray(fact.id, ids),
      ),
    )
    .returning({ id: fact.id });
  return rows.length;
}
```

```ts
/**
 * What every loop in one user mind run reads: her live summary and what she has learned since
 * it, read once before the loops so each sees the same memories even if an earlier loop fails;
 * and the run's triggers in plain words.
 */
import { listFactsForSummary, type FactRow } from "@/db/repos/user/facts";
import { liveSummary, summaryInputFactIds, type Trigger } from "@/db/repos/user/user-mind";
import { MINUTE } from "@/mind/platform/time";
import type { UserLoopDeps } from "./runner";

export type RunInputs = {
  previous: FactRow | null;
  facts: Awaited<ReturnType<typeof listFactsForSummary>>;
};

export async function loadRunInputs(
  deps: Pick<UserLoopDeps, "db" | "config">,
  userId: string,
): Promise<RunInputs> {
  const { db } = deps;
  const settings = deps.config.user_mind.summarise;
  const previous = await liveSummary(db, userId);
  // Memories are dated by when their exchange began, so one whose cold path committed after
  // the last summary can be dated before it: look back a little, minus what it already read.
  // ponytail: a cold path the daily sweep recovers can commit later than the slack; widen it if
  // those memories matter
  const since = previous
    ? new Date(previous.created_at.getTime() - settings.since_slack_minutes * MINUTE)
    : null;
  const consumed = previous ? await summaryInputFactIds(db, userId, previous.id) : [];
  const facts = await listFactsForSummary(db, userId, since, consumed, settings.max_facts);
  return { previous, facts };
}

export function triggerText(t: Trigger): string {
  switch (t.kind) {
    case "param_jump":
      return `${t.param} between you just ${t.to > t.from ? "rose" : "fell"} sharply`;
    case "param_band":
      return `${t.param} between you just ${t.to > t.from ? "rose" : "fell"}`;
    case "salient_fact":
      return "they told you something important";
    case "make_up_done":
      return "you two made up after a hurt";
  }
}

/** The memories as a loop's prompt shows them. */
export function memoryLines(inputs: RunInputs) {
  return inputs.facts.map(({ subject, kind, content }) => ({ subject, kind, content }));
}
```

```ts
/**
 * Her idea for one user after a big event: one thing she wants to bring up with them next time,
 * or nothing. An idea gets one chance, in her next reply or as a reason to write first, and
 * expires unused after a few days.
 */
import { z } from "zod";
import { insertFact } from "@/db/repos/user/facts";
import { listOpenThreads } from "@/db/repos/user/threads";
import { liveIdeas, liveSummary, recentReflections } from "@/db/repos/user/user-mind";
import { fitText } from "@/mind/platform/llm/fit";
import { loadPrompt } from "@/mind/platform/prompts";
import { HOUR } from "@/mind/platform/time";
import { memoryLines, type RunInputs } from "./inputs";
import { runUserLoop, type UserLoopDeps } from "./runner";

/** Ideas created at or before this are past their chance. */
export function ideaCutoff(now: Date, ttlDays: number): Date {
  return new Date(now.getTime() - ttlDays * 24 * HOUR);
}

export async function userIdeate(
  deps: UserLoopDeps,
  run: { id: string; user_id: string; created_at: Date },
  inputs: RunInputs,
): Promise<"done" | "failed"> {
  const { config, db } = deps;
  const settings = config.user_mind.ideate;
  const userId = run.user_id;
  return runUserLoop(deps, run, "user_ideate", async (ctx) => {
    const now = deps.clock.now();
    const summary = await liveSummary(db, userId);
    // This run's reflection, if reflect wrote one: an older one isn't news.
    const [latest] = await recentReflections(db, userId, 1);
    const noticed = latest && latest.created_at >= run.created_at ? latest : null;
    const planned = await liveIdeas(db, userId, ideaCutoff(now, settings.ttl_days), 20);
    // A sensitive storyline's title can carry what the sensitive fact says.
    const threads = await listOpenThreads(db, userId, config.user_mind.summarise.max_threads, {
      excludeSensitive: true,
    });
    const Output = z.object({ idea: fitText(settings.max_chars).nullable() });
    const out = await ctx.deps.llm.classifyJson({
      purpose: "user_ideate",
      model: "user_mind",
      system: loadPrompt("user-mind/ideate", config.prompts.user_ideate),
      input: JSON.stringify({
        who_you_are: deps.snapshot,
        summary: summary?.payload ?? null,
        noticed: noticed?.content ?? null,
        new_memories: memoryLines(inputs),
        open_threads: threads.map((t) => t.title),
        already_planned: planned.map((i) => i.content),
      }),
      schema: Output,
      timeoutMs: config.models.structured_timeout_ms,
      maxTokens: settings.max_tokens,
    });
    let ideaId: string | null = null;
    if (out.idea) {
      const [embedding] = await deps.embedder.embed([out.idea], "document");
      const row = await insertFact(db, userId, {
        subject: "shared",
        kind: "idea",
        content: out.idea,
        embedding: embedding!,
        created_at: now,
        status: "open",
        salience: settings.salience,
        valence: 0,
        confidence: settings.confidence,
        source: "generated",
        source_ref: `user_ideate:${ctx.traceId}`,
      });
      ideaId = row.id;
    }
    return {
      inputs: {
        summary_id: summary?.id ?? null,
        reflection_id: noticed?.id ?? null,
        fact_ids: inputs.facts.map((f) => f.id),
        planned_ids: planned.map((i) => i.id),
      },
      outputs: { idea_id: ideaId },
      promptVersion: config.prompts.user_ideate,
    };
  });
}
```
