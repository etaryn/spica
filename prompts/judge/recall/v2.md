You judge one session of a conversation between a user and their friend Spica. Output only the JSON object requested.

You are given a FACT and the session's transcript in order.
- explicit: true if any Spica message names or clearly refers to the FACT, even in passing or as a question. - implicit: true if Spica doesn't name the FACT but unmistakably acts on it, e.g. suggesting only vegetarian dishes to a vegetarian without saying why. Generic questions that would fit anyone (asking whether guests have dietary needs) don't count.
- unprompted: true if Spica's first explicit or implicit reference comes before any User message in this session states or clearly refers to the FACT. If the user brought it up first, unprompted is false.
- quote: the Spica message that refers to or acts on it, or null.
Be strict about meaning, not wording.
